A single small program that writes one warm, surprising line about a small good thing that happened today to `/output/entry.txt` — a stray cat that usually bolts finally deciding to stay and blink, like a tiny truce has been agreed.

## Run it

```sh
node main.ts
```

It validates the line (single line, 1–200 characters) and writes it to `/output/entry.txt`.
